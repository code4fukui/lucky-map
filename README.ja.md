# lucky-map

衛星地図上に日本の市町村をランダムに表示するシンプルなWebアプリケーションです。

## デモ

https://code4fukui.github.io/lucky-map/

画面には「幸運を感じる」ボタン、現在地の名称を示すリンク、およびインタラクティブな衛星地図が配置されています。

## 機能

- **ランダムな場所:** ページ読み込み時に、衛星地図上に日本の市町村をランダムに表示します。
- **新たな発見:** 「幸運を感じる」ボタンをクリックすると、新しい場所がランダムに表示されます。
- **直接リンク:** 表示された市区町村の公式Webサイトへのリンクを提供します。
- **インタラクティブな地図:** インタラクティブな衛星地図を利用して、その場所をピンポイントで表示します。

## 使い方

1. [デモページ](https://code4fukui.github.io/lucky-map/)にアクセスします。ランダムな場所が自動的に表示されます。
2. **幸運を感じる** ボタンをクリックすると、新しい場所が生成されます。
3. 地図の中心が新しい場所に移動し、地図の上部にその名称が表示されます。
4. リンクされた市区町村名をクリックすると、公式Webサイトにアクセスできます。

## 技術スタック

本プロジェクトは、以下の技術を使用して構築された静的なHTMLアプリケーションです。

- **データソース:** [localgovjp-utf8.csv](https://code4fukui.github.io/localgovjp/localgovjp-utf8.csv) （座標や公式URLを含む日本の地方自治体データ）
- **地図ライブラリ:** [gsi-map](https://github.com/code4fukui/gsi-map) （国土地理院の地図を表示するためのWebコンポーネント）
- **CSVパーサー:** [CSV.js](https://github.com/code4fukui/CSV) （位置データのパース用）
